English

Summary

Wash&Shine does not collect, store, or transmit any user data. All image processing happens entirely on your device. The app has no servers, no analytics, no advertising, no accounts, and no network communication of any kind.

Data we collect

None. Wash&Shine does not collect personal information, usage analytics, crash reports, location, contacts, advertising identifiers, or any other form of data.

Image handling

The image you choose with the system photo picker is loaded into the app's memory solely to render it on screen for the cleaning interaction. The image is never copied to the app's own storage, never written to any persistent file, never uploaded to any server, and never shared with any third party. Closing the app discards the loaded image.

Permissions we use

None requiring user consent. Wash&Shine uses Apple's PhotosPicker (PHPicker), which lets you choose a single image without granting the app any access to the rest of your photo library. No permission dialog is shown. The app does not request access to camera, microphone, location, contacts, full photo library, Bluetooth, motion sensors, or any other system resource.

Local storage

The app stores a small amount of preference and game-record data on the device using Apple's UserDefaults system. This data never leaves the device. It consists of:

  • Your selected overlay type (dirt or mist)
  • Your selected effect mode (plain, water jet, or wind)
  • Your selected UI language (Japanese or English)
  • Best score and best clear time per challenge difficulty (Easy / Normal / Hard)

You can clear this data at any time by deleting the app.

Network usage

Wash&Shine does not perform any network communication. It does not load remote content, fetch updates from any server, or send any data outside the device. The app works fully without an internet connection.

Third-party services

Wash&Shine does not integrate any third-party SDKs, analytics tools, or advertising networks. The app uses only Apple's first-party frameworks (SwiftUI, PhotosUI, Foundation).

Children

Wash&Shine is rated 4+ and is suitable for all ages. Because the app does not collect any data, no special considerations are required under children's privacy regulations such as COPPA or GDPR-K.

Changes to this policy

If this privacy policy changes in a future version of the app, the updated policy will be published at this URL. Material changes will be noted at the top of this page along with the new revision date.

日本語

概要

Wash&Shine はユーザーのデータを一切収集・保存・送信しません。すべての画像処理は完全に端末内で行われます。サーバ、アナリティクス、広告、アカウント、ネットワーク通信は一切ありません。

収集する情報

ありません。Wash&Shine は個人情報、利用統計、クラッシュレポート、位置情報、連絡先、広告識別子など、いかなるデータも収集しません。

画像の取り扱い

システム標準の写真選択 UI で選んだ画像は、アプリ内のメモリに読み込まれて画面表示および拭き取りインタラクションの描画のためにのみ使用されます。アプリ独自のストレージへのコピー、永続ファイルへの書き出し、サーバへのアップロード、第三者との共有はいずれも行いません。アプリを終了すると読み込んだ画像は破棄されます。

使用するパーミッション

ユーザーの同意が必要なパーミッションは使用しません。Wash&Shine は Apple の PhotosPicker (PHPicker) を使用しており、これは写真ライブラリ全体へのアクセス権を付与することなく、ユーザーが選択した 1 枚の画像のみをアプリに渡す仕組みです。パーミッションのダイアログは表示されません。カメラ、マイク、位置情報、連絡先、写真ライブラリ全体、Bluetooth、モーションセンサー、その他のシステムリソースへのアクセスは一切要求しません。

端末内データ

本アプリは Apple の UserDefaults を使用して、わずかな設定値とゲーム記録を端末内に保存します。これらのデータが端末外へ出ることはありません。内容は以下のとおりです:

  • 選択中のオーバーレイ種別 (汚れ / モヤモヤ)
  • 選択中のエフェクトモード (プレーン / 水流 / 風流)
  • 選択中の UI 言語 (日本語 / 英語)
  • チャレンジモードの難易度別ベストスコアとベストクリアタイム (Easy / Normal / Hard)

アプリを削除することでこれらのデータはいつでも消去できます。

ネットワーク利用

Wash&Shine はネットワーク通信を一切行いません。リモートからのコンテンツ読み込み、サーバからの更新取得、外部へのデータ送信のいずれも発生しません。インターネット接続なしで完全に動作します。

第三者サービス

Wash&Shine にはサードパーティ SDK、アナリティクスツール、広告ネットワークは一切組み込まれていません。Apple の純正フレームワーク (SwiftUI、PhotosUI、Foundation) のみを使用しています。

お子様の利用について

Wash&Shine は 4+ 区分で全年齢向けです。一切のデータを収集しないため、COPPA や GDPR-K 等の児童プライバシー関連法令に関する特別な配慮は不要です。
