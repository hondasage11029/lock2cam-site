English

Summary

Lock2Cam does not collect, store, or transmit any user data. All camera frames and object detection results are processed entirely on the device and discarded as soon as they leave the screen.

Camera

The app uses the device's rear camera solely to display the live video feed and run on-device object detection (Apple Vision + CoreML). Camera frames are held in memory only and are never written to disk, uploaded to any server, or shared with any third party.

Data we collect

None. Lock2Cam does not collect personal information, usage analytics, crash reports, location, contacts, photos, advertising identifiers, or any other form of data.

Third-party services

Lock2Cam does not integrate any third-party SDKs, analytics tools, or advertising networks. Object detection runs locally via Apple's Vision framework using the YOLOv3 sample model from Apple's Machine Learning Models catalog (Apple Sample Code License).

Children

Lock2Cam is rated 4+ and is suitable for all ages. Because the app does not collect any data, no special considerations are required under children's privacy regulations such as COPPA or GDPR-K.

Changes to this policy

If this privacy policy changes in a future version of the app, the updated policy will be published at this URL. Material changes will be noted at the top of this page along with the new revision date.

日本語

概要

Lock2Cam はユーザーのデータを一切収集・保存・送信しません。カメラ映像および物体認識結果はすべて端末内で処理され、画面表示後ただちに破棄されます。

カメラについて

本アプリは、デバイス背面カメラの映像をリアルタイム表示し、端末内で物体検出 (Apple Vision + CoreML) を行うためにのみカメラを使用します。映像フレームはメモリ内で処理されるのみで、ディスクへの保存、サーバへのアップロード、第三者との共有は一切行いません。

収集する情報

ありません。Lock2Cam は個人情報、利用統計、クラッシュレポート、位置情報、連絡先、写真、広告識別子など、いかなるデータも収集しません。

第三者サービス

Lock2Cam にはサードパーティ SDK、アナリティクスツール、広告ネットワークは一切組み込まれていません。物体検出は Apple Vision フレームワーク経由で、Apple Machine Learning Models カタログ提供の YOLOv3 サンプルモデル (Apple Sample Code License) を端末内で実行しています。

お子様の利用について

Lock2Cam は 4+ 区分で全年齢向けです。一切のデータを収集しないため、COPPA や GDPR-K 等の児童プライバシー関連法令に関する特別な配慮は不要です。
